Term 2 Transition — Dynamic Data Flow & Mobile Component Mapping

Self-Learning Goal:
On Day 2, you will learn how to make React components reusable by passing custom data using Props, render dynamic lists using .map(), and see how these exact components map to React Native for mobile apps next term.

1. What are Props?

Components act like customizable building blocks. Just as HTML tags accept attributes (like src="..." or href="..."), React components accept Props (short for properties).

Props allow a parent component (like App) to pass information down to a child component (like TaskItem).

Key Rule: Props are read-only. A child component reads the props it receives, but cannot modify them directly.

2. Rendering Lists with Array .map()

In standard JavaScript, rendering an array required writing a for loop and manually creating DOM elements. In React, we use the JavaScript array method .map() inside curly braces to convert each data object into a JSX component.

function TaskList({ tasks }) {
  return (
    <section id="tasksList">
      {tasks.map((task) => (
        <TaskItem
          key={task.id}
          name={task.name}
          date={task.date}
          priority={task.priority}
          consultant={task.consultant}
          completed={task.completed}
        />
      ))}
    </section>
  );
}
Why is the key prop necessary?
React requires a unique key prop for list items so it can keep track of elements efficiently when updating the page.

3. The Bridge to Term 2: React Web to React Native

The component structure and props patterns you are practicing today in React Web are 100% identical to what you will write in React Native next term for mobile apps. The main difference is the tags used to render the UI.

UI Element React Web Tag (Term 1 End) React Native Mobile Tag (Term 2)
Container Box <div className="..."> <View style={...}>
Text Output <p>, <span>, <h1> <Text>
Clickable Button <button onClick={...}> <TouchableOpacity onPress={...}>
Text Input Field <input type="text" /> <TextInput />
