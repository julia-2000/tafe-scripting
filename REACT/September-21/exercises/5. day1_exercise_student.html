Task 2: Build a UserProfile Component

Create a component named UserProfile that returns a static profile card containing:
  • A heading <h3> with your name.
  • A paragraph displaying your role (e.g., Role: Software Development Student).
  • A styled button with text "View Profile" using className="btn".
  • A card container wrapper using className="card".

Task 3: Build a CourseInfo Component & Fix JSX Errors

Convert the following faulty HTML snippet into a valid React Component named CourseInfo: 
<!-- Convert this HTML snippet into JSX inside CourseInfo component -->
<div class="card">
  <h3>Course Details</h3>
  <label for="courseCode">Course Code:</label>
  <input id="courseCode" value="ICT50220" disabled>
  <br>
  <p>Term 2: Mobile App Development</p>
</div>

JSX Syntax Checklist to Fix:

  • ☐ Replace class="..." with className="...".
  • ☐ Replace for="..." with htmlFor="...".
  • ☐ Ensure self-closing tags like <input> and <br> are explicitly closed with a trailing slash (<input />, <br />).

Task 4: Assemble in the App Component

Include both <UserProfile /> and <CourseInfo /> components inside your main <App /> component and refresh your page to verify the output.
