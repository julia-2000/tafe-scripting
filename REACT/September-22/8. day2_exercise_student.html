Task 2: Build a Configurable HeaderBar Component

Create a HeaderBar component that accepts custom text via props:
  • Destructure two props: title and subtitle.
  • Render the title in an <h1> tag and subtitle in a <p> tag inside a container with className="header-box".

Task 3: Build a CourseCard Component using Props

Create a reusable CourseCard component that accepts individual course details:
  • Destructure props: code, title, term, and status.
  • Display code and title inside an <h3> element.
  • Display term in a paragraph and status inside a styled badge (className="badge").
  • Include a button with text "View Syllabus" (className="btn").
  • Wrap the output in a card div (className="card").

Task 4: Build CourseList with Array .map()

Create a CourseList component that receives the courses array as a prop:
  • Use courses.map() to render a <CourseCard /> for every item in the array.
  • Pass all necessary course properties (code, title, term, status) as props into <CourseCard />.
  • Crucial: Remember to pass a unique key={course.id} to each card inside the list.

Task 5: React Native Mental Mapping Exercise

Before running your code, complete this quick self-check mapping HTML elements to React Native elements for Term 2:
  • ☐ <div className="card"> translates to <View style={styles.card}>
  • ☐ <h3> and <p> translate to <Text>
  • ☐ <button className="btn"> translates to <TouchableOpacity><Text>...</Text></TouchableOpacity>
