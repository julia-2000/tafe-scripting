Day 1: Converting Task Manager to React Components

Zero-Install Setup, Component Decomposition & JSX

Self-Learning Goal:
By the end of Day 1, you will refactor your Term 1 Task Manager HTML layout into modular React function components using JSX, running directly in your web browser via CDN links.

1. Purpose of This Guide

In Term 1, you built web pages by writing standard HTML files and updating elements using JavaScript DOM manipulation (`document.createElement`, `appendChild`).

In Term 2, you are preparing to build mobile applications with React Native. Before jumping into mobile code, you need to understand how React splits UI into reusable components using JSX syntax.

2. Paradigm Shift: Imperative vs. Declarative

To understand why modern web and mobile developers use React, look at how UI generation changes between standard JavaScript and React:

Concept Plain JS (Imperative) React Components (Declarative)
DOM Creation Manually create nodes (`document.createElement('div')`). Declare HTML-like structure directly using JSX inside function components.
DOM Assembly Manually append children (`parent.appendChild(child)`). Nest components naturally inside each other (`<App><Header /><TaskForm /></App>`).
UI Structure Single massive HTML file with deeply nested code. Modular components (`<Header>`, `<TaskForm>`, `<SingleTask>`, `<SearchForm>`).

 ├── Header Component (Navigation & Title)
 ├── TaskForm Component (Task Inputs)
 ├── SingleTask Component (Static Task Display)
 └── SearchForm Component (Search Layout)

3. Running React via CDN (Zero Installation)

For Day 1, you do not need to install Node.js, NPM, or build tools. We include React, React-DOM, and Babel directly in our HTML file using CDN script tags.

Key CDN Script Tags:
  • react.development.js: Core React framework logic.
  • react-dom.development.js: Renders React components into the web browser's DOM.
  • babel.min.js: Transforms JSX code in `<script type="text/babel">` into regular JavaScript in real time.

4. Essential JSX Rules

JSX looks like regular HTML, but it is parsed as JavaScript under the hood. Keep these rules in mind when converting your Term 1 HTML layout:

  • ☐ Use className instead of class for CSS styling.
  • ☐ Use htmlFor instead of for inside <label> tags.
  • ☐ Explicitly close all self-closing tags (e.g., <input />, <br />).
  • ☐ Component functions must start with a Capital Letter (e.g., TaskForm, not taskForm).
  • ☐ Component return statements must return a single top-level element (e.g., wrapped in a <div> or Fragment).

5. Component Decomposition

1. Header Component

Converts your Term 1 header navigation bar into a standalone component.

function Header() {
  return (
    <header>
      <h1>Task Manager (React Day 1)</h1>
      <nav>
        <a href="#home">Home</a>
        <a href="#tasks">Tasks</a>
        <a href="#contact">Contact</a>
      </nav>
      <br />
      <button type="button" className="theme-toggle">Dark Theme</button>
    </header>
  );
}

2. Task Form Component

Converts input controls and form fields into a reusable component block.

function TaskForm() {
  return (
    <form id="addForm" onSubmit={(e) => e.preventDefault()}>
      <label htmlFor="taskName">Task Name</label>
      <input id="taskName" required placeholder="e.g. Build UI Components" />

      <label htmlFor="taskDate">Due Date</label>
      <input id="taskDate" type="date" required />

      <label htmlFor="taskPriority">Priority</label>
      <select id="taskPriority">
        <option>Low</option>
        <option>Medium</option>
        <option>High</option>
      </select>

      <button type="submit">Add Task</button>
    </form>
  );
}

3. Single Task Display Component

Renders a single static card representation of a task item.

function SingleTask() {
  return (
    <div className="taskarea">
      <p>Name: Fix Login Bug, Due: 2026-04-10, Priority: High, Consultant: Gina Smith</p>
      <div className="actions">
        <button type="button">Complete</button>
        <button type="button">Delete</button>
      </div>
    </div>
  );
}
